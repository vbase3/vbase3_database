Comparative Immunogenomics Across Jawed Vertebrates

VBASE3 provides an independent, open, and synthesis-ready tripartite antibody and TCR gene database containing 2,857 canonical Class I genes in the master export (2,651 V, 93 D, and 113 J segments) spanning 53 vertebrate species taxa, alongside 8,329 total functional alleles across 43 species-level catalogs, 3,114 curated TCRBase genes, 2,048 PaCMAP manifold points, and 3,900 Rosetta Stone cross-database mappings. Screened across 55 chromosome-level reference assemblies and verified against over 46 million physiological repertoire reads with sub-millisecond Rust SIMD vector alignment and strict IMGT synthesis boundaries (TVSS/TVSA for Heavy; VEIK/LEIK for Kappa; TVL for Lambda), every sequence is classified based on empirical physiological rearranged evidence with zero constant region bleed-through.

💻 Command Line & Node.js WASM Execution
Node.js v18+ Compatible

The exact same client-side WebAssembly binary (dnaplot_wasm_bg.wasm) can be invoked directly from the terminal or integrated into high-throughput Node.js pipelines without a browser:

# 1. Run canonical landmark sample from terminal:
node developer_scripts/vbase3_wasm_cli.mjs --sample humIGHV3-23

# 2. Analyze query sequence with custom species hint:
node developer_scripts/vbase3_wasm_cli.mjs --seq "CAGGTACAGCTGAAGGAGTC..." --species mouse

# 3. Batch repertoire processing with AIRR TSV output:
node developer_scripts/vbase3_wasm_cli.mjs --fasta sample.fasta --format tsv
